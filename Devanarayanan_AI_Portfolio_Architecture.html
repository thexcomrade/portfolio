4. Granular Subsystem Deep-Dive

4.1. Procedural Background Canvas Engine (SpaceBackground.tsx)

To eliminate the heavy bundle overhead associated with 3D libraries (e.g., Three.js), the background is driven by a custom, hardware-accelerated 2D Canvas engine:

  • HiDPI Display Calibration: Dynamically recalculates canvas buffer width and height using Math.min(window.devicePixelRatio || 1, 2) to guarantee crisp rendering on Retina displays without unnecessary GPU memory pressure.
  • Mathematical Mouse Spotlight: Interpolates cursor coordinates $(x_m, y_m)$ using smoothing factor $0.08$ and computes an inverse radial falloff gradient:
    $$\text{Intensity}(r) = \text{rgba}(54, 247, 249, 0.05 \cdot (1 - r / 280))$$ yielding an interactive proximity illumination that follows user movement.
  • Sinusoidal Cyber Scanlines: Generates horizontal raster lines drifting downward at $14\text{px/s}$ across $84\text{px}$ intervals, modulated by:
    $$\alpha(y, t) = 0.03 + 0.015 \cdot \sin(y \cdot 0.015 + t \cdot 0.5)$$
  • Adaptive Resource Management: Hooks into the Page Visibility API (document.hidden) and prefers-reduced-motion media query to cancel animation frames when the user switches tabs or prefers reduced motion.

4.2. Viewport-Locked 2.5D Parallax Hero Stage (Hero.tsx)

The Hero component anchors the user's initial impression through a multi-tier depth illusion:

  • Viewport Containment: Strictly bound on desktop to height: 100vh; height: 100dvh; max-height: 100vh; overflow: hidden; with padding-top: 84px. This guarantees that downstream sections (such as About) do not peek into view before scrolling.
  • Mobile Responsiveness: On screens $\le 1080\text{px}$, CSS rules automatically release the height lock to height: auto; min-height: 100vh; overflow: visible; allowing the left content and right stage to stack naturally.
  • 3D Perspective Tilt Matrix: Relative mouse coordinates over the visual stage calculate tilt angles:
    $$\text{tilt}_x = 8 \cdot \left(\frac{e.\text{clientX} - \text{rect.left}}{\text{rect.width}} - 0.5\right), \quad \text{tilt}_y = -8 \cdot \left(\frac{e.\text{clientY} - \text{rect.top}}{\text{rect.height}} - 0.5\right)$$
  • Depth Hierarchy Stack:
    1. Layer 0 (Ambient Glow): Radial blur projector casting deep cyan luminescence behind the torso.
    2. Layer 1 (Typographic Artwork): back.png with cyan drop-shadow counter-translated against cursor tilt and masked via linear-gradient(to bottom, black 0%, black 35%, transparent 52%) so no letter stems peek beneath the subject's arms.
    3. Layer 2 (Orbital Halo): Tilted glowing cyan ring with an animated traveling orbital spark running a 7s loop.
    4. Layer 3 (Foreground Subject): nanappan.png with dual drop-shadow rim lighting floating forward in Z-space.
    5. Layer 4 (Volumetric Mist): Base blur gradient softening hard bottom edges.
    6. Layer 5 (Telemetry HUD): Impact quotes and telemetry labels ("ML", "DATA", "SOLUTIONS") pinned at top: 10%.

6. Dual-Pipeline Conversion & Message Delivery Architecture

The contact subsystem in components/Contact.tsx ensures zero message loss through a fault-tolerant dual-route architecture delivering inquiries directly to devanarayananstackuplearning@gmail.com:

Route 1 — Web3Forms Background API (Primary): When NEXT_PUBLIC_WEB3FORMS_KEY is configured in .env.local, form submission initiates an asynchronous HTTP POST request to https://api.web3forms.com/submit. The message is verified against spam honeypots and delivered to Gmail with complete sender headers and reply-to configuration.
Route 2 — Pre-Populated Native mailto: (Fail-Safe Fallback): If the API key is unconfigured or a network failure occurs, the client automatically constructs a URI-encoded mailto: link containing the user's name, email, subject, and message. This triggers the native mail client pre-addressed to devanarayananstackuplearning@gmail.com, ensuring 100% communication reliability.
  • Content-Aware Subject Recommendation: Employs synchronous keyword matching inside a pure useMemo hook. Typing terms like "collab", "job", or "ai" automatically yields clickable subject chips without extra re-renders.
  • Quick-Copy Utility: An interactive pill displays devanarayananstackuplearning@gmail.com alongside a one-click copy button powered by navigator.clipboard.writeText with animated visual confirmation.
  • Radial Menu: Uses polar coordinates ($x = r \cos\theta, y = r \sin\theta$) to orbit social links (GitHub, LinkedIn, Instagram, Resume) around a central toggle button.
